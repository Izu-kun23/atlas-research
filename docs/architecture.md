# Architecture decisions

## Keep the application executable without cloud infrastructure

LangGraph orchestration · TF-IDF retrieval · optional OpenAI web search · SQLite report history. FastAPI serves the interface and API from one origin. SQLite is intentional for the single-user local portfolio scope; PostgreSQL and distributed workers are future scaling decisions rather than unused dependencies.

## Separate core logic from delivery

Domain algorithms and schemas do not depend on HTTP request objects. Services coordinate work. Provider and storage concerns live in infrastructure modules. Main is the composition root.

## Reproducibility before complexity

Seeded datasets and fixed corpora make notebooks and regression checks deterministic. No claimed result is generated by a UI placeholder.

## Explicit deployment scope

Default: `RESEARCH_MODE=demo`. For live research, set `RESEARCH_MODE=live`, `OPENAI_API_KEY`, and optionally `OPENAI_MODEL` in your shell. The application does **not** automatically load `.env`; use `uvicorn --env-file .env` with `python-dotenv` installed, or export variables. API usage incurs provider charges. No browser-side keys.

The local retrieval layer uses sparse TF-IDF, not an embedding database. The specialized agents are bounded processing roles in a graph, not autonomous agents with arbitrary tools. Demo findings are extractive paraphrases. Live evidence consists of provider-cited excerpts, not independently downloaded documents. Exact quote validation establishes provenance, not semantic entailment or factual truth. Small excerpts can omit context. No fake confidence score is presented.
